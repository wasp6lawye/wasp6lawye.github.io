标准制作流程

从零构建一个可游玩的 CS1.6 地图

1

环境搭建

  • 创建 Map 文件并设置世界坐标。
  • 使用 Vertex Tool 绘制基础地形。
  • 添加 Brush 并赋予材质。
2

实体放置

  • 放置 Trigger_* 实体用于碰撞检测。
  • 放置 Info_player_* 实体作为出生点。
  • 设置 Func_door 等动态物体。
3

脚本与逻辑

  • 连接逻辑门，设置 KeyValues 参数。
  • 配置武器掉落点。
  • 测试并修正逻辑错误。
4

发布与优化

  • 执行 VVIS 和 VIS 计算。
  • 使用 BSP Compiler 生成 .bsp 文件。
  • 放入 cstrike/maps 目录。

常见问题 (FAQ)

解决 CS1.6 地图编辑中的疑难杂症

Q: Hammer 编辑器无法启动或闪退怎么办？
A: 确保安装了 Steam 版 Counter-Strike 1.6。Hammer 通常位于 Steam 安装目录下的 cstrike 目录中。尝试以管理员权限运行，或重新安装 cstrike 目录。
Q: 地图生成后没有贴图或颜色全黑？
A: 这通常是因为没有进行 VVIS 和 VIS 计算。在 Hammer 中点击 Map -> Map Information -> Compile，确保勾选了 VVIS 和 VIS，并点击 Run Map Compilation。
Q: 如何在地图中添加自定义音效？
A: 将 .wav 音效文件放入 cstrike/sound 目录。在 Hammer 中放置 info_soundscape 实体或使用 Ambient_generic 实体，并在 KeyValues 中引用 sound 文件路径。
